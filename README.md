# Paradise Nursery Shopping Application

A React + Vite plant shopping application with Redux Toolkit.

## Features

- Welcome landing page
- About Paradise Nursery section
- Indoor and Outdoor plant categories
- Plant image, name, and price
- Add to Cart
- Cart item quantity controls
- Remove items
- Total item count
- Per-item total
- Grand total amount
- Continue Shopping
- Checkout button
- Responsive design

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.
